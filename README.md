# 🚗 Car Rental Database — Система управления прокатом автомобилей

Реляционная база данных для автоматизации работы пункта проката автомобилей. Разработана на **Microsoft SQL Server** с использованием **T-SQL**.

---

## 📌 О проекте

Проект реализует базу данных для учёта:
- 🚘 Автомобилей и их характеристик
- 👥 Клиентов и их ролей
- 🏢 Пунктов проката
- 📄 Договоров аренды
- 📅 Бронирований

---

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| Microsoft SQL Server | СУБД |
| T-SQL | Язык запросов |
| SSMS | Средство разработки |

---

## 📊 Структура базы данных

### Таблицы

| # | Таблица | Описание | Первичный ключ |
|---|---------|----------|----------------|
| 1 | `roles` | Роли пользователей | `role_id` |
| 2 | `punkt_prokata` | Пункты проката | `id_punkta` |
| 3 | `auto` | Автомобили | `marka` |
| 4 | `client` | Клиенты | `id_client` |
| 5 | `dogovor` | Договоры аренды | `id_dogovora` |
| 6 | `bron` | Бронирования | `id_broni` |
