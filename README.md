#  Car  Database — Система управления автомобилями

Реляционная база данных для автоматизации работы пункта проката автомобилей. 

 О проекте

Проект реализует базу данных для учёта:
-  Автомобилей и их характеристик
-  Клиентов и их ролей
-  Пунктов проката
-  Договоров аренды
-  Бронирований

---

## Технологии

| Технология | Назначение |
|------------|------------|
| Microsoft SQL Server | СУБД |
| T-SQL | Язык запросов |
| SSMS | Средство разработки |
